# Istanbul Doner — сайт быстрого заказа (Хромтау)

Статический сайт без сборки и без сервера: гость собирает заказ, нажимает кнопку —
открывается WhatsApp кафе с готовым текстом заказа. Данные, отзывы и фото взяты из
[карточки кафе в 2ГИС](https://go.2gis.com/PraD3).

## Структура

```
site/                 ← это и есть сайт, заливать на хостинг нужно только эту папку
  index.html          ← ГЛАВНАЯ-витрина: о кафе, «скидка дня», плитки разделов, отзывы, фото, контакты
  menu.html           ← СТРАНИЦА ЗАКАЗА: меню, корзина, оформление и отправка в WhatsApp
  css/style.css
  js/config.js        ← НАСТРОЙКИ: номер WhatsApp, часы, меню и цены, галерея
  js/reviews.js       ← отзывы для сайта (генерируется скриптом, руками не править)
  js/app.js           ← логика: меню, корзина, сообщение в WhatsApp
  img/                ← оптимизированные фото
data/                 ← выгрузка из 2ГИС
  istanbul_2gis.json  ← всё в одном файле: профиль, атрибуты, 79 отзывов, 15 фото, меню
  reviews.csv         ← все отзывы таблицей (открывается в Excel, разделитель «;»)
  menu.json           ← меню, расшифрованное с фото меню-борда
  photos/original/    ← 15 фото из карточки (1440 px — максимум, что отдаёт 2ГИС)
  photos/reviews/     ← 7 фото, прикреплённых к отзывам
  raw/                ← сырые ответы API 2ГИС
tools/build_data.py   ← пересобирает data/*.json, reviews.csv и site/js/reviews.js из data/raw
```

## Языки

При первом посещении открывается казахская версия. Переключатель **ҚАЗ / РУС**
в шапке запоминает выбор. Прямые ссылки: `?lang=kk` и `?lang=ru`.
Корзина и заполненные поля заказа сохраняются при переключении.

Словарь переводов интерфейса и меню находится в `site/js/i18n.js`.
При добавлении блюда в `config.js` добавьте его название и описание в словарь.
Цены и идентификаторы блюд общие для двух языков. Отзывы публикуются на языке оригинала.

## Две страницы

«Оформить заказ» и плитки разделов на главной ведут на `menu.html` (можно сразу к разделу или блюду:
`menu.html#cat-combo`, `menu.html#item-combo-doner`; `menu.html#cart` открывает корзину). Корзина общая
для обеих страниц: на главной плавающая кнопка показывает «Меню и заказ» либо содержимое корзины.
Обе страницы подключают один `js/app.js` — каждая его часть запускается, только если на странице есть её разметка.

## Скидка дня

`deals` в `site/js/config.js`: на какие блюда (`items`), сколько процентов (`percent`), в какие дни недели
(`days`, пусто — каждый день), с какой по какую дату (`from` / `until`), `active: false` — выключить.
Показывается первая подходящая на сегодня акция: большой блок на главной и полоска на странице заказа.
Цена со скидкой считается сама — в меню, корзине и в тексте заказа («Скидка дня: −250 ₸»).
**⚠️ Сейчас там демо-пример (−10% на комбо «Doner»), кафе такую акцию не объявляло** — согласовать или выключить.

## Картинка при отправке ссылки (og:image)

Мессенджеры показывают `site/img/og.jpg` (1200×630). Она свёрстана в `brand/og/card.html` (три варианта: `?a`, `?b`, `?c`)
и рендерится командой `sh brand/og/render.sh` (нужен Google Chrome) → `brand/og/out/og-a|b|c.jpg`; нужный вариант
скопировать в `site/img/og.jpg`. На картинке «зашиты» рейтинг и часы работы — если изменятся, перерендерить.
Адрес картинки в `og:image` обязан быть абсолютным; после замены картинки увеличить `?v=` в её адресе во всех трёх
HTML, иначе мессенджеры покажут старую из кэша. При переезде на свой домен заменить `github.io`-адреса в og-тегах.

## Политика конфиденциальности

`site/privacy.html` — на русском и казахском (показывается версия по языку сайта), ссылка в подвале и у кнопки
отправки заказа. Закон РК «О персональных данных и их защите» требует согласия на обработку (ст. 7–8) и документа
с политикой оператора (ст. 25). Текст описывает реальную схему сайта: данные не уходят на сервер, гость сам отправляет
заказ в WhatsApp, на устройстве хранятся корзина и поля формы (на странице есть кнопка «Удалить мои данные»).
**⚠️ Перед запуском:** вписать реквизиты кафе в `legal` (`config.js`) и дать владельцу прочитать пункты 2, 6 и 7 —
это обещания от имени кафе (данные только для заказа, передаются только курьеру, удаление по просьбе).
Если появятся аналитика, реклама или своя база заказов — политику нужно дополнить (база с персональными данными
по ст. 12 должна храниться на территории Казахстана).

## Как поменять меню, цены, номер

Всё в `site/js/config.js` — там комментарии на русском.

- **Новое блюдо:** добавить строку `{ id: 'cola-05', name: 'Кола 0,5 л', price: 450, emoji: '🥤' }` в нужную категорию.
- **Новая категория:** скопировать блок `{ id, title, items: [...] }`.
- **Скрыть блюдо/категорию:** `hidden: true`.
- **Номер для заказов:** `contacts.whatsapp` (только цифры, с кодом страны).

- **Напиток с вариантами** (`type: 'options'`): группы `groups` — вкус (`style: 'select'` — выпадающий список)
  и объём (кнопки); цена = сумма `price` выбранных вариантов.
- **Вопрос после добавления** (бесплатный соус к фри): группа с `optional: true` — сайт спросит её
  всплывающей подсказкой сразу после добавления и ещё раз в корзине, на цену она не влияет.
- **Предложения к покупке:** `upsell` — что предложить после какого блюда («к донеру — фри и кола»),
  `cartSuggest` — блок «Добавить к заказу?» в корзине, `upsellExclusive` — категории, где хватит одной
  позиции (есть напиток — другие не предлагаем), `covers` у комбо — что в него уже входит.

### Что нужно дозаполнить

**⚠️ Напитки и соусы — заглушки.** Ассортимент, вкусы и цены напитков взяты с сайта-референса
(0,5 л) и прикинуты (1 л); из соусов с меню-борда известен только «острый соус — 100 ₸».
Перед запуском сверить с кафе — всё помечено `⚠️` в `config.js`.


На фото меню-борда из 2ГИС видна только правая часть, поэтому на сайте сейчас: донеры,
комбо, фри, наггетсы, перчик. **Нет цен на бургеры, пиццу, хот-доги и напитки**, а у секции
Chicken (2 090 / 3 390 / 4 590 ₸) обрезано количество штук — она лежит в конфиге с
`hidden: true`: впишите количество в `name` и уберите `hidden`.

## Посмотреть локально

```bash
python3 -m http.server 4173 --directory site
```

и открыть http://localhost:4173 (или просто открыть `site/index.html` в браузере).

## Публикация

Подойдёт любой статический хостинг: перетащить папку `site/` в Netlify Drop, либо
GitHub Pages / Cloudflare Pages.

## Обновить отзывы

Сырые ответы API лежат в `data/raw/`. После их обновления: `python3 tools/build_data.py`.
Какие отзывы показывать на сайте — список `SITE_REVIEW_IDS` в начале скрипта.

## Про фото

Все 15 фото в карточке 2ГИС загружены гостями (на них водяной знак 2GIS). Для сайта
отобраны 7 лучших; снимки с упаковкой другого заведения и с людьми в кадре не использованы.
Когда появятся собственные фото блюд — лучше заменить ими (файлы в `site/img/`, список в `config.js`).
